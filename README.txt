AEROSPACE CAD PRESENTATION

Run locally:
1. Extract this ZIP.
2. Open the aerospace-cad-presentation folder in VS Code.
3. Install the Live Server extension if needed.
4. Right-click index.html and choose Open with Live Server.
5. Keep an internet connection for Three.js, GSAP, and Google Fonts loaded from CDNs.

Controls: Arrow keys / Space to navigate, F for fullscreen, drag the 3D models to rotate them, and use component buttons when shown.

Troubleshooting: If the page remains on the loading screen, refresh with Ctrl+Shift+R and check the browser Console. Do not type terminal commands into the browser Console; run node --check app.js in the VS Code Terminal.
